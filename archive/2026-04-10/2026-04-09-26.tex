\begin{mistake}{2026-04-09}{26}

\begin{problemcontent}
求极限 \( \lim_{x \to 0} \dfrac{\cos(\sin x) - \cos x}{(1 - \cos x)\sin^2 x} \)。
\end{problemcontent}

\begin{solutioncontent}
使用泰勒展开（麦克劳林公式）法求解。

先处理分母：当 \( x \to 0 \) 时，\( 1 - \cos x \sim \frac{1}{2}x^2 \)，\( \sin x \sim x \)。
故分母 \( (1 - \cos x)\sin^2 x \sim \frac{1}{2}x^4 \)。分母为 \( x \) 的四阶无穷小，因此分子必须展开至 \( x^4 \) 阶。

再展开分子：
已知 \( \cos u = 1 - \frac{1}{2}u^2 + \frac{1}{24}u^4 + o(u^4) \)。
代入 \( u = \sin x = x - \frac{1}{6}x^3 + o(x^3) \)：
计算 \( u^2 = (\sin x)^2 = (x - \frac{1}{6}x^3)^2 = x^2 - \frac{1}{3}x^4 + o(x^4) \)。
代入得到 \( \cos(\sin x) = 1 - \frac{1}{2}(x^2 - \frac{1}{3}x^4) + \frac{1}{24}x^4 = 1 - \frac{1}{2}x^2 + \frac{5}{24}x^4 + o(x^4) \)。

已知 \( \cos x = 1 - \frac{1}{2}x^2 + \frac{1}{24}x^4 + o(x^4) \)。
分子相减：
\( \cos(\sin x) - \cos x = \left( \frac{5}{24} - \frac{1}{24} \right)x^4 + o(x^4) = \frac{1}{6}x^4 + o(x^4) \)。

最终极限计算：
\( \lim_{x \to 0} \dfrac{\frac{1}{6}x^4}{\frac{1}{2}x^4} = \dfrac{1}{3} \)。
\end{solutioncontent}

\mistakeknowledge{
\begin{itemize}
 \item \textbf{核心公式}：泰勒展开式 \( \cos x = 1 - \frac{1}{2}x^2 + \frac{1}{24}x^4 + o(x^4) \) 及 \( \sin x = x - \frac{1}{6}x^3 + o(x^3) \)。
 \item \textbf{易错点}：复合函数展开精度不够。将 \( (\sin x)^2 \) 误判展开为 \( x^2 \)，遗漏了展开平方过程中的交叉项 \( -\frac{1}{3}x^4 \)，导致系数计算错误。
 \item \textbf{关联知识}：等价无穷小替换原则在加减法中的失效机制（需保证展开项“上下同阶”）。
\end{itemize}}

\end{mistake}
