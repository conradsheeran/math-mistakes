\begin{mistake}{2026-07-23}{02}

\begin{problemcontent}
设 \(L\) 是一条平面曲线，其上任意一点 \(P(x,y)\) (\(x>0\)) 到原点的距离恒等于该点处的切线在 \(y\) 轴上的截距，且 \(L\) 过点 \((\frac{1}{2},0)\)。求：\\
(I) 曲线 \(L\) 的方程；\\
(II) \(L\) 位于第一象限部分的一条切线，使该切线与 \(L\) 以及两坐标轴所围的面积最小。
\end{problemcontent}

\begin{solutioncontent}
(I) 设点 \(P(x,y)\)，到原点距离为 \(\sqrt{x^2+y^2}\)。切线在 \(y\) 轴上的截距为 \(y - x y'\)。
依题意有：
\[ y - x y' = \sqrt{x^2+y^2} \]
两边同除以 \(x\) (\(x>0\))，化为一阶齐次方程：
\[ y' = \frac{y}{x} - \sqrt{1+\left(\frac{y}{x}\right)^2} \]
令 \(u = \frac{y}{x}\), 则 \(y = ux\), \(y' = u'x + u\), 代入得：
\[ u'x + u = u - \sqrt{1+u^2} \implies \frac{du}{\sqrt{1+u^2}} = -\frac{dx}{x} \]
积分得 \(\ln(u + \sqrt{1+u^2}) = -\ln x + \ln C\), 即 \(u + \sqrt{1+u^2} = \frac{C}{x}\)。
将 \(u = \frac{y}{x}\) 代回得 \(y + \sqrt{x^2+y^2} = C\)。
代入初始条件 \((\frac{1}{2},0)\), 得 \(C = \frac{1}{2}\)。
整理 \(\sqrt{x^2+y^2} = \frac{1}{2} - y\), 两边平方化简得：
\[ y = \frac{1}{4} - x^2 \quad (x>0) \]

(II) \(L\) 在第一象限部分满足 \(0 < x < \frac{1}{2}\)。设切点为 \((x_0, \frac{1}{4}-x_0^2)\)。
切线斜率 \(k = -2x_0\), 切线方程为 \(y = -2x_0 x + x_0^2 + \frac{1}{4}\)。
切线在两坐标轴上的截距分别为 \(y_A = x_0^2 + \frac{1}{4}\), \(x_B = \frac{x_0^2 + 1/4}{2x_0}\)。
切线与坐标轴围成的直角三角形面积：
\[ S_{\triangle} = \frac{1}{2} x_B y_A = \frac{(x_0^2 + 1/4)^2}{4x_0} \]
所求阴影面积 \(S = S_{\triangle} - S_L\), 其中 \(S_L\) 为常数, 故 \(S\) 最小等价于 \(S_{\triangle}\) 最小。
令 \(f(x_0) = \frac{(x_0^2 + 1/4)^2}{4x_0}\), 求导：
\[ f'(x_0) = \frac{48x_0^4 + 8x_0^2 - 1}{64x_0^2} \]
令 \(f'(x_0) = 0\), 因 \(x_0>0\), 解 \(48(x_0^2)^2 + 8x_0^2 - 1 = 0 \implies (12x_0^2 - 1)(4x_0^2 + 1) = 0\), 得 \(x_0 = \frac{\sqrt{3}}{6}\)。
此时切线方程为：
\[ y = -\frac{\sqrt{3}}{3} x + \frac{1}{3} \]
\end{solutioncontent}

\mistakeknowledge{
\begin{itemize}
  \item \textbf{核心公式}：切线 \(Y - y = y'(X - x)\), 在 \(y\) 轴上的截距为 \(y - xy'\)；齐次方程 \(y'=f(\frac{y}{x})\) 换元 \(u=\frac{y}{x}\)。
  \item \textbf{易错点}：化简齐次方程时, 将 \(x\) 移入根号内需保证 \(x>0\)；解面积最值时应剥离定值面积（曲边梯形）, 转化为动三角形面积最值。
  \item \textbf{关联知识}：积分表基本公式 \(\int \frac{du}{\sqrt{1+u^2}} = \ln(u + \sqrt{1+u^2}) + C\)。
\end{itemize}}

\end{mistake}
